Design System

Vibe:
Cozy bookshop meets playful social app. Warm paper tones, personality, and movement.
Fonts:
Lora (serif, italic) — titles, numbers, headings
DM Sans — body, labels, UI
Member Colors (muted, configurable):
Maya — #7B9EC9 (muted blue)
Mina — #C97B9E (muted pink)
Heenal — #9E7BC9 (muted purple)
Key Rules:
— Chip color = who picked the book (not which column)
— Column separators: neutral 0.5px lines only, no color fills
— -1000 row sits directly below 1, above unrated
— Admin sets group background photo (preselected options)
— Member profile objects on shelf (customizable per member)
